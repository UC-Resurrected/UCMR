UNCHARTED 2: AMONG THIEVES

Bring your own game data. Then play online.

This guide walks through the files the launcher needs for multiplayer, then the RPCN connection used to sign in. Complete the steps in order.

MP

Before you begin

You need a legally owned copy of Uncharted 2, its decrypted game executable, and an RPCS3 installation with game data.

The guide does not provide game files, keys, or account credentials.

01

GAME SOURCE

Select your PS3 game folder

Choose the folder for your own Uncharted 2 Game of the Year copy. It should contain USRDIR; choosing USRDIR itself also works.

Example pathD:/PS3 Games/Uncharted 2 - Among Thieves GOTY [NPUA80698]
02

RPCS3 DATA

Locate the game data folder

In your RPCS3 installation, select dev_hdd0/game. This folder contains the installed data used when Uncharted 2 goes online.

Typical locationRPCS3/dev_hdd0/game
03

EXECUTABLE

Choose the decrypted EBOOT

Select the decrypted EBOOT.elf from your own game copy. It is normally inside the game’s USRDIR directory.

Expected file.../NPUA80698/USRDIR/EBOOT.elf
04

LAUNCHER

Import the multiplayer files

Open the launcher’s Multiplayer section. Add the game folder, RPCS3 game-data folder, and EBOOT path from the previous steps. Choose an output location, then run RE-IMPORT / UPDATE.

Wait for the import to finish before launching. The launcher will show that the game has been imported when it is ready.

05

RPCN ONLINE PLAY

Connect your account

In the launcher, enter the community server DNS supplied by the server you use. Select or add your RPCN account, then confirm both DNS and account status show green.

READY CHECKDNS reachable · RPCN account signed in

READY TO PLAY

Launch into multiplayer

Once all five checks are complete, select Play in the launcher. During play, use Insert or R3 + L2 to open the in-game menu.
